# Генератор КП

Вебгенератор комерційних пропозицій: заповнюєш форму, отримуєш зверстану КП у PDF (через «Зберегти PDF» → друк у PDF).

- Реквізити компанії, каталог продукції, логотип, печатка й підпис лежать в окремому файлі даних компанії.
  Він завантажується в браузер користувача, зберігається тільки там і нікуди не надсилається.
- Без файлу даних сторінка відкривається з демонстраційною компанією.
- Формат `kp.json` сумісний зі скілом `kp-zgraya`.

Шрифт документа: Zlam, якщо він встановлений на комп’ютері; інакше Geologica (OFL). Цифри: Geist Mono (OFL).
